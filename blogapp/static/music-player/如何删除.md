# 🗑️ 安全移除播放器功能指引

## 删除步骤

### 1. 删除文件夹
直接删除整个 `music-player` 文件夹

### 2. 清理 HTML 引用
打开以下文件，删除相关代码：

#### `blogapp/templates/auth/login.html`

删除这一行（在 `<head>` 标签内）：
```html
<!-- 全局音乐播放器样式 -->
<link rel="stylesheet" href="{{ url_for('static', filename='music-player/css/music-player.css') }}">
```

删除这一行（在 `</body>` 标签前）：
```html
<!-- 全局音乐播放器脚本 -->
<script src="{{ url_for('static', filename='music-player/js/music-player.js') }}"></script>
```

### 3. 完成
删除完成，不会影响任何其他功能。

---

## 如果以后添加了其他页面

如果你在其他页面也引用了音乐播放器，记得也要删除那些页面里的引用代码。

搜索关键词：`music-player`
